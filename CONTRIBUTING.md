# 🤝 Contributing Guide

Thank you for your interest in contributing to NexaraSovereign!

---

## Our Ethos

This project is irrevocably dedicated to the welfare of all humanity and future generations.  
Stewardship, not ownership—every contribution must uphold public good, transparency, and dignity.

---

## How to Contribute

1. **Fork the repository** and create your branch from `main`.
2. **Write clear, documented, and testable code.**
3. **Add or update documentation** if your change affects public APIs or workflows.
4. **Run all tests** before submitting your Pull Request (PR).
5. **Submit a descriptive PR** and link any relevant issues.

---

## Contribution Checklist

- [ ] Code follows the project’s ethical principles and style.
- [ ] No private profiteering, backdoors, or non-transparent code.
- [ ] Documentation is updated where necessary.
- [ ] All significant changes are logged in [AUDIT.md](./AUDIT.md).
- [ ] PR passes all CI checks and reviews.

---

## Reporting Issues

- Use GitHub Issues for bugs, suggestions, and questions.
- For security vulnerabilities, see [SECURITY.md](./SECURITY.md).

---

## Community

By participating, you agree to follow our [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) and stewardship principles.

**Your code, your ideas, and your stewardship make a difference.**
